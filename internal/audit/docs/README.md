# audit

## Context

Most projects accumulate supply chain blind spots silently — no Dependabot, secrets committed by mistake, no SAST in CI, Dockerfiles running as root. This package scans for those gaps across the full security surface and offers one-step fixes backed by pre-configured templates. It detects the project's ecosystem automatically (Go, Node.js, Python, Java) and only runs the checks that apply.

## When to use

Run on any existing or new project to get a security posture report and apply fixes interactively:

```bash
cd my-project
mr-agent-ai audit
```

## What it checks and generates

### Checks

| Section | What it verifies |
|---------|-----------------|
| Supply Chain | Dependabot config, lock files, npm/Python shelf-time |
| Secrets | `.gitignore` patterns, `.env` not tracked in git, pre-commit hooks, secret scanner |
| SAST | CodeQL, gosec (Go), bandit (Python), eslint-security (Node) |
| Containers | No `:latest` base image, non-root `USER`, Trivy in CI |
| IaC | Checkov/Terrascan for Terraform and docker-compose |
| GitHub Actions | `permissions:` declared in all workflow files |

### Files generated by fixes

| Fix | File |
|-----|------|
| Dependabot | `.github/dependabot.yml` |
| .gitignore secrets | appended to `.gitignore` |
| Pre-commit hooks | `.pre-commit-config.yaml` |
| Secret scanner | `.gitleaks.toml` |
| SAST (Go) | `.github/workflows/sast.yml` |
| SAST (Python) | `.github/workflows/sast.yml` |
| SAST (Node) | `.github/workflows/sast.yml` |
| Container scan | `.github/workflows/trivy.yml` |
| IaC scan | `.github/workflows/iac-scan.yml` |
| npm shelf-time | appended to `.npmrc` |

## Adding a new check

1. Add the detection helper to `checks.go`
2. Add the fix logic to `fixer.go` (add a template to `content/` if needed)
3. Wire both from `scanner.go`
